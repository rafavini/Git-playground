Problema

Configurar o Git, entender comandos e ter medo de quebrar o projeto afastam quem está começando.

💻

Prática

Terminal, editor e arquivos reais no navegador. Cada comando reage visualmente na tela.

🧩

Desafio

Puzzles progressivos: de git init até conflitos de merge e recuperação de arquivos.

🎮

Gamificação

XP, níveis, conquistas, sequência diária e ranking para manter a motivação lá em cima.

🧠

Aprendizado

Erros viram explicações. Você entende o porquê, não só o comando.

⌨️

Terminal que parece de verdade

Prompt com branch, histórico, autocomplete com Tab, cores e respostas idênticas às do Git real.

🎬

Veja o Git acontecendo

Working Directory → Staging → Commit → Remote com animações e um grafo de commits clicável.

🛟

Erros que ensinam

Digitou git commmit? O playground explica o que aconteceu e sugere o caminho certo.

💡

Dicas sem spoiler

Dicas progressivas custam um pouco de XP — a solução só aparece depois da última.

🏆

Conquistas e ranking

Medalhas como "Sobreviveu ao Merge Conflict" e uma disputa amigável entre os alunos.

💾

Nada se perde

Progresso, arquivos e estado do repositório ficam salvos no seu navegador.
